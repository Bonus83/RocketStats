# Contributing

RocketStats accepts bug reports, questions, and feature requests through
[GitHub Issues](https://github.com/Bonus83/RocketStats/issues).

Pull requests are not accepted. Please open an issue to describe a problem or
suggestion instead. Public GitHub repositories may still allow PR submissions;
unrequested PRs may be closed without review.

Do not post account identifiers, player data, full game logs, or other private
information in an issue. Include only the minimum details needed to describe
the problem.
